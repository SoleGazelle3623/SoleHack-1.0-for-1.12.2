Addons are now here! If you wanna make a Addon, go to https://github.com/SoleGazelle3623/SoleHack-Addon-Example 

## Building from Source
1. Clone the repository: `git clone https://github.com`
2. Navigate to the folder and build using Gradle:
3. go to cmd and do commands like "gradlew setupdecompworkspace, and gradlew build"
4. Find your compiled `.jar` file inside `build/libs/`.
